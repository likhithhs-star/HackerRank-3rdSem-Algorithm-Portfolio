# Insertion Sort - Part 1

**HackerRank:** https://www.hackerrank.com/challenges/insertionsort1/problem

## Approach
Store the final element as the value to insert. Shift larger elements one position to the right until the correct position is found, then insert the stored value.

The array is printed after every shift and after the final insertion.

## Complexity
- Time: O(N) for this single insertion operation
- Auxiliary Space: O(1)

## Edge Case
If the final element is already in the correct position, no shifts are required.
