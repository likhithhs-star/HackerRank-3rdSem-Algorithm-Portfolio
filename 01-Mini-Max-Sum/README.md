# Mini-Max Sum

**HackerRank:** https://www.hackerrank.com/challenges/mini-max-sum/problem

## Approach
Calculate the total sum of all five values, while tracking the minimum and maximum values.

- Minimum sum = total - maximum
- Maximum sum = total - minimum

This avoids sorting and requires only one traversal.

## Complexity
- Time: O(N)
- Auxiliary Space: O(1)

## Edge Case
If all five values are equal, the minimum and maximum sums are equal.
